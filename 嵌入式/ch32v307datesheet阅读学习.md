## FLASH部分![img](3084836-20251217130345337-95918475.png))
展示了从0x00000000到0x1FFFFFFF的地址空间分配情况  
1. 最底部（0x 0000 0000开始）  
标注为【aliased to flash or system memory depending on BOOT pins】  
这是启动地址映射区，芯片上电时会根据BOOT引脚的电平状态，决定从哪里加载并且执行第一行代码    
 - 如果BOOT引脚设置为【从FLASH启动】，这里就映射到下面的Code FLASH区域  
 - 如果设置为【从系统内存启动】，就映射到System FLASH区域(用于固件升级等等)  

- - -
2. Code FLASH区域（0x 0800 0000开始，最大480kb）  
用户程序存储区，编写的代码编译后就烧录到这里  
标注的「includes 0 wait and non-0 waiting areas」是指它内部有不同访问速度的区域  
 - 0 wait area访问时不需要等待周期，速度最快  
 - non-0 wait area访问时需要等待1个或者多个等待周期，速度稍微慢点  
- - -
3.  System FLASH（0x1FFF8000 开始，BOOT_28KB）  
这是系统引导闪存，由芯片厂商预先写入的引导程序（Bootloader）喵  
通常用于：  

- 芯片出厂时的初始引导  
- 通过串口/USB等方式进行固件升级（ISP/IAP功能）  
- - -
4. Vendor Bytes（0x1FFF7000）和Option Bytes（0x1FFF800）  
- Vendor Bytes：存放芯片厂商的信息（比如型号、版本等）    
- Option Bytes：芯片的配置选项（比如看门狗设置、读保护、写保护等），可以通过程序修改    
- - -
5. 保留区域（Reserved）  
图中灰色部分是预留区域，暂时未分配功能，可能是预留给未来扩展或厂商内部使用的  
- - -
## 完整部分![img](3084836-20251217131500080-893287669.png))
- - -
先看整体结构：
地址从下往上递增，不同颜色/标注代表不同功能的内存区域。咱喵从最底部开始，逐层往上解析每个区域的作用和特点～😉

1. FLASH（0x00000000 开始）
这是程序存储器，和之前那张图的Code FLASH类似，但这里是完整的FLASH区域喵😺

功能：存储你编写的程序代码、常量数据（比如const修饰的变量）、中断向量表等
特点：非易失性（掉电不丢失）、只读（运行时一般不能修改，需要特殊指令擦写）
编程应用：C语言编译后的.bin或.hex文件就烧录到这里，芯片上电后从这里开始执行第一条指令✨
2. SRAM (128KB max)（0x20000000 开始）
这是静态随机存储器，程序运行时的数据就放在这里喵😊

功能：存储全局变量、局部变量、堆（heap）、栈（stack）等动态数据
特点：易失性（掉电丢失数据）、读写速度快（比FLASH快很多）
容量：最大128KB（具体看芯片型号，CH32V307系列的不同型号可能有差异）
编程应用：你在程序中定义的变量（比如int a = 10;）默认就存在这里，函数调用时的临时数据也通过栈在这里操作✨
3. Reserved（0x20010000 - 0x3FFFFFFF）
这是预留区域，暂时未分配功能，可能是预留给未来扩展或厂商内部使用的喵😺

4. Peripherals（0x40000000 开始）
这是外设寄存器映射区，芯片的所有外设（比如GPIO、UART、SPI、定时器等）的控制寄存器都映射在这里喵✨

功能：通过访问特定地址（寄存器地址）来控制外设的工作状态
访问方式：在C语言中，通常用指针或结构体来访问这些寄存器（比如GPIOA->ODR = 0x0001;控制PA0引脚输出高电平）
编程应用：这是嵌入式编程的核心！比如配置UART波特率、设置GPIO引脚方向、读取ADC采样值等，都需要操作这里的寄存器😉
5. Reserved（0x40000000 以上部分）
继续往上的灰色区域也是预留区域，直到FSMC相关区域喵😺

6. FSMC相关区域（灵活静态存储控制器）
FSMC是CH32V307的一个重要外设，用于扩展外部存储器（比如NOR FLASH、PSRAM、NAND FLASH等），这部分区域是FSMC的地址映射：

6.1 FSMC bank1 NOR/PSRAM 1（0x60000000 - 0x63FFFFFF）
功能：映射外部NOR FLASH或PSRAM存储器的第1个存储块
应用：如果你的项目需要更大的存储空间，可以通过FSMC外接NOR FLASH，程序运行时可以直接访问这里的地址（像访问内部内存一样方便）✨
6.2 FSMC bank2 NAND (NAND1)（0x70000000 - 0x73FFFFFF）
功能：映射外部NAND FLASH存储器
特点：NAND FLASH容量更大但读写速度稍慢，常用于存储大量数据（比如固件升级包、日志等）
6.3 FSMC register（0xA0000000 - 0xA000FFFF）
功能：FSMC外设自己的控制寄存器区域
应用：编程时需要先配置这里的寄存器，才能正常使用FSMC接口（比如设置存储类型、时序参数等）喵😊
7. 更多Reserved区域
FSMC以上直到Core Private Peripherals的区域都是预留的喵😺

8. Core Private Peripherals（0xE0000000 - 0xE01FFFFF）
这是内核私有外设区域，包含了与CPU核心紧密相关的外设：

常见外设：NVIC（嵌套向量中断控制器）、SysTick（系统定时器）、MPU（内存保护单元）等
功能：控制CPU的中断响应、系统时钟、内存访问权限等核心功能
编程应用：比如配置中断优先级、设置系统滴答定时器的频率、开启内存保护等，都需要操作这里的寄存器✨
9. 最高地址：Reserved（0xE0200000 - 0xFFFFFFFF）
最顶部的区域也是预留的，暂未使用喵😺

总结一下这张图的核心价值：
这张图就像CH32V307芯片的「内存地图导航」，告诉你：

✨ 程序代码该存在哪里（FLASH）
💾 运行时数据该存在哪里（SRAM）
🎮 外设控制寄存器在哪里（Peripherals区域）
📦 外部扩展存储怎么映射（FSMC区域）
⚙️ CPU核心功能怎么配置（Core Private Peripherals）
有了这张图，你在编程时就能准确知道「操作哪个地址」来实现你想要的功能啦～😺 是不是很有用呀？
